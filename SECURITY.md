# Security

Incursa.Quic is a .NET QUIC, HTTP/3, QPACK, and DNS-over-QUIC library. Treat security reports as private until maintainers have triaged the affected package, protocol behavior, or documentation.

## Reporting

Do not report secrets, exploit details, private transcripts, local credential paths, or reproducible vulnerability details in a public issue or pull request.

Use GitHub private vulnerability reporting if it is enabled for this repository. If it is unavailable, contact security@incursa.com.

For general open-source project questions, contact oss@incursa.com.

Please include:

- affected package, version, commit, or branch
- affected protocol area, if known
- reproduction steps or proof outline
- observed impact
- whether the issue exposes credentials, private paths, local artifacts, or unsafe defaults

## Supported Versions

For unreleased builds, only the latest `main` branch or current release candidate is expected to receive security fixes.

## Public Boundary

Keep reports and fixes free of private repository paths, private ProtocolLab artifacts, credentials, local Codex auth state, and unpublished customer or operator data.

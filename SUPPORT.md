# Support

Use GitHub issues for reproducible bugs, documentation gaps, and focused change proposals in this repository.

For security vulnerabilities, do not open a public issue. Follow [SECURITY.md](SECURITY.md).

For general open-source project questions, contact oss@incursa.com.

Incursa.Quic is maintained as an open-source library. Maintainers may close issues that are missing reproduction details, depend on private artifacts, request support for private deployments, or are outside this repository's QUIC, HTTP/3, QPACK, DNS-over-QUIC, package, documentation, and governance scope.

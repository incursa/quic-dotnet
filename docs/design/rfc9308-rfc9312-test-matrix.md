# RFC 9308 and RFC 9312 Test Matrix

This matrix is limited to items that are meaningfully testable. RFC 9308 and RFC 9312 are informational, so explanatory text, deployment preference, and application-design advice are not treated as automatic code obligations.

Source material:

- RFC 9308 raw text: `https://www.rfc-editor.org/rfc/rfc9308.txt`
- RFC 9312 raw text: `https://www.rfc-editor.org/rfc/rfc9312.txt`
- SpecTrace variants: `SPEC-QUIC-RFC9308.json`, `SPEC-QUIC-RFC9312.json`
- Classification report: `docs/design/rfc9308-rfc9312-spectrace-classification.md`

## Helper And Fake Network Components

- `QuicConnectionStreamStateTestHelpers`: stream limits, flow-control credit, stream snapshots.
- `QuicPostHandshakeTicketTestSupport` and `QuicResumptionClientHelloTestSupport`: resumption and dormant 0-RTT setup.
- `QuicPathMigrationRecoveryTestSupport`: active path, NAT rebinding, path validation, recording diagnostics sink.
- `QuicS8P2PathValidationTestSupport`: PATH_CHALLENGE/PATH_RESPONSE packet helpers.
- `QuicCoalescedPacketRuntimeTestSupport`: coalesced Initial/Handshake server flight.
- `QuicConnectionIdLifecycleTestSupport`: NEW_CONNECTION_ID and RETIRE_CONNECTION_ID runtime helpers.
- `QuicRetryIntegrityUnitTests` / `QuicRetryPacketRequirementTestData`: Retry packet construction and validation fixtures.
- `QuicHeaderTestData`: Version Negotiation and invariant header packet builders.
- `QuicRecordingDiagnosticsSink`: assertion-friendly diagnostics sink for runtime tests.
- Proposed `FakeQuicKeepAlivePolicyClock`: deterministic idle/keep-alive timer driver if keep-alive policy is added or surfaced.
- Proposed `FakeDatagramTransportProfile`: deterministic DATAGRAM enabled/disabled transport-parameter setup if the DATAGRAM advertisement surface becomes configurable.
- Proposed `FakeIcmpPacketTooBigSource`: helper to build valid and invalid quoted packets for ICMP PTB runtime events.

## Prioritized Implementation Order

1. Close required-now gaps that are direct regressions over current behavior: `ZeroRttApplicationData_IsRejectedWhenEarlyDataAdmissionIsClosed`, `FlowControlBlockedStream_ResumesAfterCreditIsReleased`, `RemoteConnectionClose_EntersDrainingAndEmitsDiagnostic`.
2. Add RFC 9312 diagnostic integration gaps around already-implemented behavior: `VersionNegotiation_DiagnosticAndQlogAreEmitted`, `RetryReceived_DiagnosticAndQlogAreEmitted`, `ConnectionIdRetirement_RemovesRouteAndToken`, `SpinBitUpdated_IsEmittedOnlyWhenSpinStateChanges`.
3. Add PMTU and ICMP negative/positive diagnostics: `PmtuProbeAcknowledged_RaisesPmtuUpdatedDiagnostic`, `PmtuProbeLost_DoesNotIncreasePathMtu`, `IcmpPacketTooBig_AcceptedReductionEmitsSafeDiagnostics`, `IcmpPacketTooBig_InvalidQuoteIsIgnoredSafely`.
4. Add boundary/advertisement tests that depend on public feature surfaces: `KeepAlivePing_IsNotEmittedWithoutApplicationKeepAlivePolicy`, `DatagramTransportParameter_AdvertisesOnlyWhenDatagramIsEnabled`.
5. Strengthen invariant/future-version parser proof with property or fuzz coverage: `UnknownFutureVersion_InvariantHeaderParsingDoesNotBreak`.

# QUIC and HTTP/3 ProtocolLab Component Parity Matrix

This audit maps local `quic-dotnet` correctness and performance proof to package-backed ProtocolLab component paths. It separates local implementation confidence, component inventory, and external-peer characterization so package-backed rows do not imply broad support unless the underlying proof is already explicit.

Sources audited:

- `C:\shared\src\incursa\quic-dotnet`
- `C:\shared\src\incursa\protocol-lab-internal`
- `C:\shared\src\incursa\protocol-lab-components`

Status values:

- `exists`: package-backed component path already exists for the row.
- `partial`: local proof and some package path exist, but coverage or scenario packaging is incomplete.
- `missing`: no concrete package-backed path exists yet.
- `blocked`: a specific external dependency, platform gap, or public package contract gap prevents a meaningful component.
- `out-of-scope`: intentionally repo-local or not appropriate for a package-backed component.
